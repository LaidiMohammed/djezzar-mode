# DJEZZAR MODE — Streetwear Batna

Boutique streetwear premium à Batna. Next.js 14 + Tailwind + Framer Motion.

- Home avec vidéo fashion men en background
- Vêtements en cartes arches organiques (pas de carrés/rectangles)
- À propos + carte Batna (OpenStreetMap)
- Commande COD avec envoi WhatsApp au 0540924588
- Admin panel : commandes / produits / stats (localStorage)
- TikTok : https://www.tiktok.com/@djezzar_mode
- Livraison 58 wilayas

## Dev

```bash
npm install
npm run dev
```

## Deploy (Vercel)

1. Push sur GitHub (déjà configuré)
2. Va sur https://vercel.com/new → Import le repo `djezzar-mode`
3. Framework: Next.js, tout par défaut → Deploy

Ou en CLI : `npx vercel --prod`
